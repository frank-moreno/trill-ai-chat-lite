## Pending for 2.2.0

### CNV-06 — CSV formula-injection hardening (OWASP) · High · ~2 pts — **implemented 2026-06-21**
`TranscriptExporter` wrote user/AI message text straight into CSV cells with no neutralisation of leading `=`, `+`, `-`, `@`, tab or CR — a formula/CSV-injection vector on open in Excel/Sheets.
- **New:** `includes/Conversations/CsvCellSanitizer.php` — stateless `sanitize($value)` (SRP): prefixes a leading `=`/`+`/`-`/`@`/tab/CR with `'`; only touches string cells so numeric columns are never corrupted.
- **Changed:** `TranscriptExporter` routes every text cell (session_id, status, customer, started/ended, role, content) through it, in both `stream_conversations_csv()` and `stream_transcript_csv()`.
- **Test:** `ExporterSmoke.php` plants a `=HYPERLINK(...)` message and asserts the exported cell is quote-prefixed and the raw `=` form never appears.

Three `wp eval-file` smoke tests, all self-cleaning, mirroring the existing harness. **All validated green on Local (2026-06-21).**
- `tests/Conversations/DeleteByIdsSmoke.php` (CNV-08) — input hardening, single delete, bulk delete + non-existent ID, no orphan messages. **Validated: 15/15 pass.**
- `tests/Conversations/ConversationQuerySmoke.php` — `sanitise_filters` (status/rating/date/search/per_page/paged), `query()` envelope + pagination + ORDER BY + status/search filters, `get_transcript()` shape. Fixtures isolated via a sentinel `started_at` on 2000-01-01.

 The CNV-06 formula-injection assertion is now included in `ExporterSmoke.php`.

## CNV-08 implementation notes (2026-06-21)

Decision: **implemented** a guarded admin delete rather than deferring to the GDPR-only path — but without a parallel delete routine.

- `includes/Gdpr/ConversationManager.php` — new public `delete_by_ids(array $ids): int`, reusing the existing private `delete_cascade()` (feedback → messages → conversations) so deletion semantics live in one place; writes a `trcl_log` audit entry.
- `includes/Admin/Admin.php` — registered `admin_post_trcl_conversation_delete`; new `handle_conversation_delete_post()` (POST-only, `check_admin_referer`, `manage_trcl_chat` gate, int-cast IDs, single-row precedence, PRG redirect via `redirect_to_conversations()` with referer validation) + three localised confirm strings.
- `includes/Admin/views/conversations.php` — wrapped the list in a POST form, added a check-column with select-all, a "Delete selected" bulk button, and a per-row "Delete" button; transient success/error notice.
- `assets/js/admin.js` — `initConversationDelete()`: select-all toggle + `confirm()` guards (UX only; server remains the security boundary). `assets/js/admin.min.js` regenerated.

Still required before release (under CNV-07 / CNV-05): unit test for `delete_by_ids`, Plugin Check pass, `.pot` regen for the new strings.
